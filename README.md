# NLP Chatbot

A simple retrieval-based chatbot developed using Python and Natural Language Processing (NLP).

## Technologies Used

- Python
- NLTK
- Newspaper3k
- Scikit-learn
- NumPy

## Features

- Extracts article content from a web page
- Splits the article into sentences
- Uses CountVectorizer for text representation
- Uses Cosine Similarity to find relevant responses
- Supports basic greetings
- Supports exit commands
